# ADR-0004：开源协议选择 AGPL-3.0

- 状态：accepted
- 日期：2026-08-24

## 背景

项目即将公开发布并接受社区贡献。候选：MIT / GPL-3.0 / AGPL-3.0 / Apache-2.0。
本品类（自托管面板）近两年密集出现新竞品，存在被 fork 后闭源商用、
不回馈上游的现实风险。

## 决策

采用 **GNU AGPL-3.0-or-later**。

## 理由

- **网络服务条款**：AGPL 要求「通过网络提供服务」的修改版也必须开源，
  直接封死「fork 面板 → 闭源商业化运营」的路径（GPL 仅约束二进制分发，
  对 SaaS 形态无效）
- 对普通贡献者（提 PR、自部署使用）几乎无感知成本
- 与项目自身的功能分层商业化规划兼容：核心保持开源，未来增值功能可独立授权

## 后果

- LICENSE 为 AGPL-3.0 全文；两个 package.json 声明 `AGPL-3.0-or-later`
- 依赖选型需注意 AGPL 传染性：新增服务端运行时依赖避免引入 GPL/AGPL 冲突库
- 二次分发或基于此项目提供网络服务者须遵守相同协议并保留版权声明
