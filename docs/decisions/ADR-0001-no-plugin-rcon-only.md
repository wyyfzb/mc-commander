# ADR-0001：无插件 RCON-only 架构

- 状态：accepted
- 日期：2026-08-08

## 背景

Minecraft 服务器管理工具主流两条路线：游戏内 GUI 插件（需装插件、进游戏）与
Web 面板（多数只提供命令透传）。服主的核心痛点是「命令繁琐易错、不可回溯」，
而非缺乏功能入口。

## 决策

MC_Commander 不依赖任何第三方插件，仅通过 **RCON 协议 + 文件系统 + 原版 HTTP 接口**
实现全部管理能力：

- 管理操作（给予/传送/封禁/踢出/OP/白名单）由面板拼装原版命令经 RCON 下发
- 需要状态回读的操作（玩家档案/统计数据/世界信息）直接解析服务端文件
  （usercache.json、stats/*.json、level.dat 等 NBT）
- 原版命令无法覆盖的能力（临时封禁、禁言等）在服务端自实现补齐（见 ADR-0002）

## 后果

- **优点**：服务端零侵入，对 vanilla/Paper/Purpur/Forge 等各类服务端通用；
  面板与游戏版本解耦
- **代价**：能力边界受原版命令与文件格式约束；MC 版本升级可能改变文件布局
  （如 26.x 数据包拆分），需要持续做版本兼容
- 排查任何「命令不生效」问题时，不假设存在 EssentialsX 等插件的命令扩展
