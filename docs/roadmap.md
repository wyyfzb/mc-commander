# 路线图

按优先级排序的功能与工程规划。欢迎在 Discussions 讨论优先级调整。

## 工程基建（进行中）

- ✅ CI 流水线（lint / typecheck / 单测 / e2e / 密钥扫描）
- ✅ 自动化 Release（tag 触发构建 + 产物发布）
- 🔲 安全加固二期：TOTP 两步验证、操作审计日志

## P0 功能（按序）

1. **经验 / 药水效果 / 召唤表单** —— 与既有给予物品表单同构，图形化拼装对应命令
2. **玩家洞察仪表盘** —— 服主周报：活跃趋势、上线轨迹、物品/成就沉淀（复用已有
   跨会话玩家档案数据）
3. **插件管理最小闭环** —— 列表 / 启停（不做依赖解析；远景：数据包与 mod 管理）
4. **文件管理增强** —— 上传 / 新建 / 重命名 / 压缩解压

## P1 规划

- 背包编辑（只读 → 可写）
- 多实例批量运维视图
- AI 助手接口预留（MCP 协议）

## P2 远景

- 远程备份目标（对象存储 / 异机同步）
- 命令历史与回放

## 不做清单（维持产品边界）

- 不进游戏、不做客户端 mod —— 「不装插件、不进游戏」是产品根基
- 不做多租户 SaaS —— 面向单管理员自托管场景
- 禁言等原版无法实现的功能不做（见 ADR-0002）
