# 贡献者行为准则

## 我们的承诺

为营造开放友善的社区，无论身份背景，参与本项目的每个人都受尊重、不被骚扰。

## 行为标准

**鼓励：**
- 使用友善包容的语言
- 尊重不同观点与经验
- 优雅接受建设性批评
- 关注社区整体利益
- 对其他成员保持同理心

**不可接受：**
- 性化用语或关注、挑衅/侮辱/贬损性评论、人身/政治攻击
- 公开或私下骚扰
- 未经许可发布他人隐私信息（如物理/电子地址）
- 其他可被合理认定为不专业环境的行为

## 责任与范围

行为准则适用于所有社区场合（Issue、PR、讨论、聊天等）。维护者有权删除/编辑/拒绝不符合本准则的内容，情节严重者可暂时或永久封禁。

## 举报

骚扰行为请通过 GitHub 私信仓库维护者举报。所有投诉都会被审慎评估。维护者有义务对举报者信息保密。

## 出处

本准则参考 [Contributor Covenant](https://www.contributor-covenant.org) 2.1 精神改编。
